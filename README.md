# Coffee Blog ☕

Coffee blog developed with HTML5 and CSS3. This site includes brewing tips, information about the origins of the world's best coffees, and personal coffee-related blogs.

## Features:
- Coffee brewing tips section.
- Information about the origins of the best coffees.
- Personal blogs with experiences and recommendations.

## Technologies used:
- HTML5
- CSS3

## How to view the project:
1. Clone the repository or download the files.
2. Open the `index.html` file in your favorite browser.

Enjoy learning about the wonderful world of coffee!
